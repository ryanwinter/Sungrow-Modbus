# Sungrow-Modbus

## Devices

Supports Sungrow devices with AES 128 encrpytion, such as the SG8K-D.

## Home Assistant

1. Add custom repository using HACS
1. Install the `Sungrow Modbus` integration
1. Add the integration into your `configuration.yaml` file
